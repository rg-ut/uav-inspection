
# 从素材上传中心发布车牌回放数据包

车牌巡检的回放数据包括时间轴、主回放、RViz 录屏、航线和取证卡片，按批次上传。

1. 部署设置中填写 `UAV_PLATE_DATA_UPLOADERS`，值为已有的登录账号，多个账号用英文逗号分隔。Docker 部署在 `deploy/.env` 中设置，新镜像部署后生效。
2. 用该账号登录平台，在**素材上传中心 → 车牌巡检数据包**选择交付 ZIP 或原始 `.tar.gz`，点击**上传并启用**。ZIP 中只读取回放压缩包及其 SHA-256 清单。
3. 等待页面显示当前批次后，点击**查看车牌回放**。校验失败时页面会给出原因，当前批次继续可用。发布成功后可点击**恢复上一批**，两项操作都即时生效。

数据包由网站分片接收，校验完整后一次切换。文件保存在 `UAV_DATA_DIR/uav-inspection-backend/platedata-versions/`，该目录与原先手工部署的 `platedata/` 都位于持久数据卷。网站启用的批次优先，切回原有批次时继续使用原来的回放目录。备份数据卷时请同时保留激活记录和版本目录。
