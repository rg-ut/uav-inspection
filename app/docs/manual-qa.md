## 玉米巡检工作台

保留原有三栏结构和白色、浅灰、玫红的视觉体系。飞行状态与任务入口位于左侧，
作业场景、进度、植株记录和动态位于中间，任务助手位于右侧。
业务界面不展示论文名称、阈值、实现边界或未接入提示。场景使用内置玉米植株资源，
不需要视频，保留“演示任务 / 三维演示”环境标识。

| 功能 | 本地浏览器验证 |
|---|---|
| 全域巡检 | 跑完整条 361 m 航线，按区域巡查、重点复核、返航执行，M01/M02 各积累三个有效观察方向，最终降落至 0.7 m，16/16 航点 |
| 重点巡检 | M01 环绕航线跑通，覆盖 8/8 方向；其余植株不虚增观察记录 |
| 快速巡查 | 高空方案可以单独选择和执行；不自动追加低空观察记录 |
| 开始、暂停、继续 | 位置、时间和进度随执行更新，暂停期间保持不变；速度 2/4/8 和倍率 1/2/4 可选 |

| 航线切换保护 | 未结束任务不能直接应用另一条航线；重置后可换线 |

| 视角与全屏 | 全景、跟随、俯视、重置观察视角、进入和退出全屏已操作 |
| 助手 | 调用任务状态、开始、暂停、继续、返航、优化视点；不支持的指令返回操作帮助 |
| 任务恢复 | 刷新恢复当前任务并保持暂停，继续后按原位置执行；任务动态一并保存 |
| 报告 | 实际生成并下载 HTML 和 JSON，包含本次轨迹、观察和机位记录；历史保留最近五个任务 |

| 响应式 | 桌面完整工作台；约 390 px 内容宽度无横向溢出，场景和记录改为纵向布局 |
